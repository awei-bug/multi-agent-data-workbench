# 合规能力说明

## 1. 导出脱敏

默认开启：

```env
WORKSPACE_EXPORT_MASK_SENSITIVE=true
```

导出会自动脱敏：

- 手机号：`138****5678`
- 邮箱：`a***@example.com`
- 身份证号：保留前后各 4 位

## 2. 导出水印

默认开启：

```env
WORKSPACE_EXPORT_WATERMARK=true
```

Markdown / HTML / Word / PDF 导出会写入水印信息：

```text
CONFIDENTIAL | <tenant>/<username>
Exported at <timestamp>
```

## 3. 数据保留策略

按天配置，`0` 表示不过期：

```env
WORKSPACE_RETENTION_HISTORY_DAYS=90
WORKSPACE_RETENTION_DATASET_DAYS=180
WORKSPACE_RETENTION_ARTIFACT_DAYS=180
WORKSPACE_RETENTION_AUDIT_DAYS=365
```

管理员执行清理：

```http
POST /api/admin/retention/purge
Authorization: Bearer <admin-token>
# 或
x-admin-api-key: <admin-key>
```

会清理当前作用域下过期的：

- 历史任务
- 数据集
- 导出/产物文件
- 审计事件

## 4. 健康检查

`GET /api/health` 会返回：

```json
{
  "security": {
    "exportWatermark": true,
    "exportMaskSensitive": true,
    "retention": {
      "historyDays": 90,
      "datasetDays": 180,
      "artifactDays": 180,
      "auditDays": 365
    }
  }
}
```

## 5. 建议生产默认

```env
WORKSPACE_EXPORT_WATERMARK=true
WORKSPACE_EXPORT_MASK_SENSITIVE=true
WORKSPACE_RETENTION_HISTORY_DAYS=90
WORKSPACE_RETENTION_DATASET_DAYS=180
WORKSPACE_RETENTION_ARTIFACT_DAYS=180
WORKSPACE_RETENTION_AUDIT_DAYS=365
```
