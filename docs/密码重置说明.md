# 密码重置说明

## 能力说明

后端提供无状态友好的密码重置接口：

1. `POST /api/auth/password-reset/request`
   - body: `{ "username": "alice" }`
   - 始终返回 `ok: true`，避免用户名枚举
   - 非生产环境会额外返回 `resetToken`，便于本地联调

2. `POST /api/auth/password-reset/confirm`
   - body: `{ "token": "...", "newPassword": "NewPass123" }`
   - 校验 token 有效期（默认 30 分钟）并一次性消费
   - 成功后更新密码哈希

## 生产落地建议

当前实现把 reset token 存于 `password_reset_tokens` 表。生产环境还应：

- 接入邮件/短信/企业 IM 发送重置链接
- 将前端重置页接到 `/reset-password?token=...`
- 对 request 接口单独限流（已有全局限流，可再按用户名细化）
- 审计事件：
  - `auth.password_reset.request`
  - `auth.password_reset.confirm`

## 本地验证

```bash
# 1) 申请重置（开发模式会回传 token）
curl -s -X POST http://127.0.0.1:8787/api/auth/password-reset/request \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin"}'

# 2) 确认新密码
curl -s -X POST http://127.0.0.1:8787/api/auth/password-reset/confirm \
  -H 'Content-Type: application/json' \
  -d '{"token":"<resetToken>","newPassword":"NewPass123"}'
```
