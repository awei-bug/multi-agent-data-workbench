# 故障排查手册

## 1. 前端打不开

现象：

- 浏览器访问前端地址失败
- 页面空白

排查：

- 确认前端开发服务是否启动
- 确认端口 `5174` 或 `8080` 是否被占用
- 如果是 Docker Compose，执行：

```powershell
docker compose ps
```

## 2. 后端启动失败

现象：

- 后端服务无法启动
- 控制台提示端口占用

排查：

- 检查 `8787` 是否已被其他进程占用
- 修改 `WORKSPACE_API_PORT`
- 检查数据库连接串是否可用

## 3. 数据库连接失败

现象：

- `/api/health` 返回数据库不可用
- `/api/health/ready` 返回 503

排查：

- 检查 `WORKSPACE_DATABASE_URL`
- 检查 PostgreSQL 用户名、密码、数据库名
- 如果使用 Compose，确认 `postgres` 服务健康

## 4. 页面提示上传失败

现象：

- 上传文件后立即报错

排查：

- 检查文件大小是否超过限制
- 检查文件格式是否在支持范围内
- 检查后端 `/api/data-source/upload` 是否可访问
- 检查产物目录是否可写

## 5. 图表或报告没有生成

现象：

- 工作流执行后没有图表
- 报告导出失败

排查：

- 检查上传的数据是否包含足够的结构化字段
- 检查需求输入是否为空
- 检查工作流是否执行到图表、报告、审核节点
- 检查后端日志中是否有模型调用失败

## 6. 管理接口返回 403

现象：

- 审计接口或删除接口返回 `403`

排查：

- 检查是否设置了 `WORKSPACE_ADMIN_API_KEY`
- 如果已设置，请确认请求头里是否带了：

```http
x-admin-api-key: 你的管理口令
```

## 7. Docker Compose 启动后访问失败

现象：

- `docker compose up --build` 后页面打不开

排查：

- 执行：

```powershell
docker compose ps
docker compose logs backend
docker compose logs frontend
docker compose logs postgres
```

- 检查前端端口 `8080` 是否冲突
- 检查后端健康检查是否通过
- 检查数据库是否完成初始化

## 8. 数据库迁移异常

现象：

- 启动时报迁移错误
- 表未创建成功

排查：

- 确认 `WORKSPACE_RUN_MIGRATIONS_ON_START=true`
- 手动执行：

```powershell
cd backend
alembic upgrade head
```

- 确认 Alembic 配置文件和迁移目录存在

## 9. 模型调用异常

现象：

- 意图解析、洞察生成结果明显异常
- 后端日志出现模型调用失败

排查：

- 检查 `APIHUB_API_KEY`
- 检查 `WORKSPACE_MODEL_BASE_URL`
- 检查 `WORKSPACE_MODEL_NAME`
- 检查外网连接情况

## 10. 最小自检顺序

建议按这个顺序排查：

1. 检查后端健康接口
2. 检查数据库连接
3. 检查前端是否能访问后端
4. 检查上传是否成功
5. 检查工作流是否推进
6. 检查图表和报告是否生成
