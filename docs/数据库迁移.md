# 数据库迁移说明

后端已接入 Alembic，用于对 PostgreSQL 表结构做版本化管理。

## 迁移文件位置

- 配置文件：`backend/alembic.ini`
- 迁移入口：`backend/migrations/env.py`
- 版本文件：`backend/migrations/versions/`

## 执行迁移

在 `backend` 目录执行：

```powershell
py -m alembic upgrade head
```

如果要连接 PostgreSQL，先设置数据库连接：

```powershell
$env:WORKSPACE_DATABASE_URL="postgresql://postgres:123456@127.0.0.1:5432/workbench"
py -m alembic -x database_url=$env:WORKSPACE_DATABASE_URL upgrade head
```

当前应用仍保留启动时自动建表，目的是兼容本地开发和测试；生产环境应优先使用 Alembic 迁移。
