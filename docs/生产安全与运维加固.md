# 生产安全与运维加固说明

## 目标

把工作台从“可部署”推进到“可上生产”的安全与运维基线：

1. 生产安全强制校验
2. HTTPS 反向代理
3. 对象存储（MinIO/S3）
4. 备份恢复
5. SSE 实时进度
6. Grafana 基础面板

## 1. 生产安全基线

环境变量：

```env
WORKSPACE_ENV=production
WORKSPACE_PRODUCTION_MODE=true
WORKSPACE_ENFORCE_PRODUCTION_SECURITY=true
WORKSPACE_AUTH_REQUIRED=true
WORKSPACE_AUTH_SECRET=<>=24 chars>
WORKSPACE_ADMIN_API_KEY=<>=16 chars>
WORKSPACE_CREDENTIALS_SECRET=<>=24 chars>
WORKSPACE_CORS_ORIGINS=https://app.example.com
WORKSPACE_ENABLE_HSTS=true
```

启动时如果生产模式安全校验失败，进程会直接退出。

强制项：

- 鉴权开启
- 强密钥
- 管理口令
- 明确 CORS
- 禁止 demo seed

安全响应头：

- `Content-Security-Policy`
- `Strict-Transport-Security`（可开关）
- `X-Content-Type-Options`
- `X-Frame-Options`
- `Referrer-Policy`
- `Permissions-Policy`

## 2. HTTPS / 网关

配置文件：

- `deploy/nginx/nginx.https.conf`
- `deploy/nginx/nginx.http.conf`

证书目录（默认）：

```text
deploy/certs/fullchain.pem
deploy/certs/privkey.pem
```

生产 compose：

```bash
docker compose -f docker-compose.production.yml --env-file .env.production up -d
```

## 3. 对象存储

支持：

```env
WORKSPACE_ARTIFACT_BACKEND=s3   # local | s3 | minio
WORKSPACE_S3_BUCKET=workbench-artifacts
WORKSPACE_S3_ENDPOINT_URL=http://minio:9000
WORKSPACE_S3_ACCESS_KEY=...
WORKSPACE_S3_SECRET_KEY=...
WORKSPACE_S3_REGION=us-east-1
WORKSPACE_S3_PREFIX=workspace-artifacts
```

本地开发可继续用 `local`。

## 4. 备份与恢复

备份：

```bash
export WORKSPACE_DATABASE_URL=postgresql://...
export WORKSPACE_ARTIFACT_DIR=workspace-artifacts
bash tools/backup.sh
```

恢复：

```bash
bash tools/restore.sh backups/workbench-YYYYMMDD-HHMMSS
```

建议：

- 每天自动备份
- 至少保留 14 天
- 每季度做一次恢复演练

## 5. SSE 实时进度

接口：

```http
GET /api/workflow/jobs/stream
```

前端工作台启动任务后会优先走 SSE，失败时自动回退轮询。

## 6. Grafana

生产 compose 已内置 Grafana：

- 默认端口：`3000`
- 面板：`deploy/grafana/dashboards/workbench-overview.json`

你需要把 Prometheus 指到后端 `/metrics`，或在 Grafana 数据源中配置。

- [ ] HTTPS 证书有效
- [ ] `AUTH_REQUIRED=true`
- [ ] 管理接口有 admin key/角色保护
- [ ] 备份脚本可跑通
