# 管理接口清单

## 1. 说明

本文档列出当前项目中已归类为管理接口的后端 API。

当后端环境变量 `WORKSPACE_ADMIN_API_KEY` 已设置时，以下接口必须带请求头：

```http
x-admin-api-key: 你的管理口令
```

或者登录为 `admin` 角色并携带：

```http
Authorization: Bearer <accessToken>
```

未设置管理口令时，仍要求 JWT 中的 `admin` 角色（本地兼容模式下默认 local 身份具备管理能力，便于开发）。

## 2. 已保护接口

### 2.1 审计查询

- `GET /api/audit/events`

用途：

- 查看当前工作区审计事件
- 用于排查敏感操作、流程回放和行为追踪

风险：

- 会暴露敏感操作记录

### 2.2 保存工作台模板

- `POST /api/templates/save-active-task`

用途：

- 将当前工作台会话固化为模板

风险：

- 可能把当前用户的任务口径、描述和摘要沉淀为可复用模板

### 2.3 删除历史任务

- `DELETE /api/history/tasks/{task_id}`

用途：

- 删除已保存的历史任务

风险：

- 会移除历史任务及其关联产物

### 2.4 删除数据集

- `DELETE /api/datasets/{dataset_id}`

用途：

- 删除已上传或沉淀的数据源

风险：

- 会删除数据文件引用
- 若误删会影响后续复盘

### 2.5 删除当前活动报告

- `DELETE /api/tasks/active/report`

用途：

- 清空当前工作台会话及其活动报告产物

风险：

- 会直接影响当前会话状态

### 2.6 用户与角色管理

- `GET /api/auth/users`
- `PATCH /api/auth/users/{user_id}/role`

用途：

- 查看同租户用户
- 调整 viewer / analyst / admin 角色

风险：

- 可提升或降低用户权限

### 2.7 最近错误事件

- `GET /api/errors/recent`

用途：

- 查看最近捕获的错误事件摘要
- 排查 Sentry / Webhook 告警对应的本地缓冲

风险：

- 可能暴露内部异常信息与请求上下文

## 3. 管理接口扩展原则

后续新增接口时，满足以下任一条件，应纳入管理接口：

- 涉及删除、清空、覆盖
- 涉及审计、内部记录、系统状态
- 涉及模板、配置、系统级资产
- 涉及可能影响多个用户或多个工作区的数据
- 涉及角色与权限变更

当前项目采用：

1. 本地账号 + JWT
2. RBAC（viewer / analyst / admin）
3. 可选管理口令（`x-admin-api-key`）

后续若进入多人协作和正式外网环境，建议继续升级为：

- 组织级权限边界
- 操作级细粒度授权
- 审计留痕与告警联动
