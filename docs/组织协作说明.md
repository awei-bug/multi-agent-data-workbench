# 组织协作说明

## 目标

在现有“租户 + 用户”隔离之上，支持同租户内的组织协作：

1. 创建组织
2. 邀请成员
3. 成员角色管理
4. 共享模板给组织成员

## 角色

组织内角色：

- `owner`：创建者，不可移除/改角色
- `admin`：可邀请成员、调整成员角色
- `member`：可查看组织、共享模板
- `viewer`：只读成员

说明：组织角色与系统 RBAC（viewer/analyst/admin）相互独立。

## API

- `GET /api/orgs`
- `POST /api/orgs`
- `GET /api/orgs/{org_id}`
- `POST /api/orgs/{org_id}/invites`
- `POST /api/orgs/invites/accept`
- `PATCH /api/orgs/{org_id}/members/{user_id}`
- `DELETE /api/orgs/{org_id}/members/{user_id}`
- `POST /api/orgs/{org_id}/share/template`

## 前端入口

设置页 → **组织协作**

1. 创建组织
2. 生成邀请 token
3. 被邀请用户粘贴 token 接受邀请
4. 共享当前任务为组织模板
5. 组织成员可在模板库看到组织共享模板

## 数据表

迁移：`0004_organizations`

- `organizations`
- `organization_members`
- `organization_invites`

组织共享模板写入 `templates`，`owner_id = __org__:{orgId}`，`source = organization`。

## 当前边界

- 已支持组织内模板共享
- 尚未支持组织级任务/数据集完整共享工作区
- 尚未支持 SSO 自动入组
