# 远程部署说明（Staging / Production）

## 目标

在镜像已推送到 GHCR 后，把指定版本部署到远程主机：

1. Staging：可自动部署
2. Production：版本标签 + Environment 审批后部署
3. 本机可通过 SSH 一键部署

## 架构

```text
GitHub Actions CD
  ├─ build-and-push  → GHCR
  ├─ deploy-staging  → SSH → staging host
  └─ deploy-production (approval) → SSH → production host
```

## 服务器准备（一次性）

### 1. 安装依赖

- Docker
- Docker Compose plugin
- curl

### 2. 创建部署目录

Staging:

```bash
sudo mkdir -p /opt/workbench
sudo chown "$USER":"$USER" /opt/workbench
```

Production:

```bash
sudo mkdir -p /opt/workbench-prod
sudo chown "$USER":"$USER" /opt/workbench-prod
```

### 3. 放置环境文件

```bash
cp .env.staging.example /opt/workbench/.env
cp .env.production.example /opt/workbench-prod/.env
```

### 4. 配置 GHCR 拉取权限

```bash
echo "$GHCR_TOKEN" | docker login ghcr.io -u <github-username> --password-stdin
```

### 5. 配置 SSH 登录（给 CI）

在目标主机写入部署公钥，并在 GitHub Secrets 配置对应私钥。

## GitHub Secrets

### Staging

| Secret | 说明 |
|---|---|
| `STAGING_HOST` | staging 主机 |
| `STAGING_USER` | SSH 用户 |
| `STAGING_SSH_KEY` | 私钥 |
| `STAGING_SSH_PORT` | 可选 |
| `STAGING_DEPLOY_PATH` | 默认 `/opt/workbench` |
| `STAGING_ENV_FILE` | 默认 `/opt/workbench/.env` |
| `STAGING_HEALTH_URL` | 默认 ready 探针 |
| `STAGING_REGISTRY_USER` / `STAGING_REGISTRY_TOKEN` | 可选 |

### Production

| Secret | 说明 |
|---|---|
| `PRODUCTION_HOST` | 生产主机 |
| `PRODUCTION_USER` | SSH 用户 |
| `PRODUCTION_SSH_KEY` | 私钥 |
| `PRODUCTION_SSH_PORT` | 可选 |
| `PRODUCTION_DEPLOY_PATH` | 默认 `/opt/workbench-prod` |
| `PRODUCTION_ENV_FILE` | 默认 `/opt/workbench-prod/.env` |
| `PRODUCTION_HEALTH_URL` | 默认 ready 探针 |
| `PRODUCTION_REGISTRY_USER` / `PRODUCTION_REGISTRY_TOKEN` | 可选 |

> 未配置对应 `*_HOST` 时，该环境部署 job 自动跳过。

## CD 行为

文件：`.github/workflows/cd.yml`

### Staging
- `v*` 标签自动部署（若配置了 secrets）
- 手动：`deploy_staging=true`

### Production
- 仅 `v*` 版本标签
- 需 GitHub Environment `production` 审批
- 手动：`deploy_production=true` 且版本号为 `v*`

详细生产流程见：

- [生产部署说明.md](./生产部署说明.md)

## 本机手动远程部署

Staging:

```bash
export DEPLOY_HOST=staging.example.com
export DEPLOY_USER=deploy
export DEPLOY_SSH_KEY_PATH=~/.ssh/staging_deploy
export IMAGE_PREFIX=ghcr.io/<owner>/<repo>
export IMAGE_TAG=v1.0.0
bash tools/ssh-deploy.sh
```

Production:

```bash
export DEPLOY_HOST=prod.example.com
export DEPLOY_USER=deploy
export DEPLOY_SSH_KEY_PATH=~/.ssh/prod_deploy
export DEPLOY_PATH=/opt/workbench-prod
export DEPLOY_ENV_FILE=/opt/workbench-prod/.env
export IMAGE_PREFIX=ghcr.io/<owner>/<repo>
export IMAGE_TAG=v1.0.0
bash tools/ssh-deploy.sh
```

## 回滚

```bash
export IMAGE_PREFIX=ghcr.io/<owner>/<repo>
export IMAGE_TAG=v0.9.0
bash tools/ssh-deploy.sh
```

## 健康检查

部署脚本默认检查：

```text
http://127.0.0.1:8787/api/health/ready
```
