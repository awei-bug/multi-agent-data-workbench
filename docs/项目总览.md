# 多 Agent 协同数据分析创作工作台 - 项目总览

## 项目定位

本项目是一个**单用户**“数据分析 + 多 Agent 协同创作”工作台 MVP。  
它已经可以完成：数据源接入、需求解析、七节点工作流、图表与报告生成、真实文件导出、历史回放和模板复用。

它**不是**企业级多租户平台。登录鉴权、组织权限、外部数据库连接器、定时任务、WebSocket 推送、分布式 Worker 属于下一阶段。

## 技术栈

- 前端：React 19、TypeScript、Vite、React Router、ECharts
- 后端：Python、FastAPI、Uvicorn
- 存储：PostgreSQL / SQLite + 本地工件目录
- 测试：Vitest、Playwright、Python unittest
- 模型：Agnes OpenAI 兼容接口（可选）

## 主用户路径

1. `/data-sources` 上传或复用数据源
2. `/workspace/input` 输入需求并解析意图
3. `/workspace/execution` 启动服务端工作流并检查产物
4. `/workspace/output` 编辑报告、导出文件、保存模板
5. `/history` / `/templates` / `/reports` 复用历史、模板和报告

## 后端能力

- 健康检查、活动任务、历史任务、模板、数据源、报告
- 数据源 multipart 上传与原文件下载
- 服务端托管工作流执行（start/resume 后自动推进）
- 节点产物：source_profile / cleaning_summary / metric_result / chart_spec / analysis / report_markdown / audit
- 真实导出：Markdown / HTML / DOCX / PDF

## 当前边界

- 已支持本地账号 + JWT + RBAC（viewer/analyst/admin）
- 已支持进程内异步工作流执行与状态轮询
- 已支持历史/模板/审计的 scope 列索引查询
- 已支持 JSON 日志与 Prometheus metrics
- 已支持 Redis 共享工作流队列（可选）与独立 worker
- 已支持 Sentry 错误追踪与 Webhook 告警
- 已支持 CD 镜像发布（GHCR）与预构建镜像部署
- 已支持 Staging 远程自动部署（SSH + compose）
- 已支持 Redis 共享限流（多实例）
- 已支持外部连接器（HTTP JSON / PostgreSQL）与凭据加密
- 已支持 Staging 自动部署与 Production 审批部署
- 线性七节点工作流，不是完整 DAG 编排平台
- 模型可选，失败时确定性回退
- 本地/Compose 演示部署，不是完整生产治理方案
