# 多 Agent 协同数据分析创作工作台 - 项目总览

## 项目定位

本项目是一个面向“数据分析 + 多 Agent 协同创作”的工作台系统。它不是单纯的数据看板，而是把数据源接入、自然语言需求解析、多 Agent 任务流、数据分析图表、报告生成、审核校验和导出管理串成一套完整流程。

当前版本已经具备可运行的 MVP 能力：前端工作台可以访问，Python 后端可以启动，PostgreSQL 已接入，模型接口已配置，主流程可以演示和继续迭代。

## 技术栈

- 前端：React 19、TypeScript、Vite、React Router DOM、Zustand、ECharts
- 后端：Python、FastAPI、Uvicorn
- 数据库：PostgreSQL
- 测试：Vitest、Playwright、Python unittest
- 大模型：通过 `https://apihub.agnes-ai.com/v1` 调用 Agnes 模型

## 前端页面

- `/workspace`：主工作台，承载多 Agent 主流程、数据预览、图表、日志、报告编辑和导出入口。
- `/data-sources`：数据源管理页，用于查看和复用样例数据。
- `/templates`：模板库，用于复用分析报告模板。
- `/workspace-async`：异步工作台沙箱，用于验证后端 API 驱动流程。
- `/history`：历史任务页，用于查看和回放历史分析任务。

## 多 Agent 主流程

1. 数据接入 Agent：接收上传数据或系统生成的样例数据。
2. 数据清洗 Agent：识别字段、检查缺失和异常。
3. 指标计算 Agent：计算销售额、订单数、毛利率、转化率等指标。
4. 可视化 Agent：生成趋势图、结构图、对比图等分析图表。
5. 洞察分析 Agent：提炼业务结论和风险点。
6. 报告生成 Agent：生成管理层报告草稿。
7. 审核校验 Agent：检查报告内容、数据口径和输出风险。

## 后端能力

- `GET /api/health`：健康检查，返回数据库和模型配置状态。
- `GET/PATCH /api/active-task`：读取和更新当前任务。
- `POST /api/workflow/action`：执行工作流动作。
- `POST /api/workflow/advance`：推进多 Agent 流程。
- `GET /api/history/tasks`：查询历史任务。
- `GET /api/templates`：查询模板。
- `GET /api/audit/events`：查询审计事件。

## 数据库配置

默认 PostgreSQL 连接：

```text
postgresql://postgres:123456@127.0.0.1:5432/workbench
```

统一启动脚本会默认使用这个连接串，也可以通过 `WORKSPACE_DATABASE_URL` 覆盖。

## 关键环境变量

- `AGNES_API_KEY` / `OPENAI_API_KEY` / `APIHUB_API_KEY`：模型密钥，三者任一可用。
- `WORKSPACE_DATABASE_URL`：PostgreSQL 连接串。
- `WORKSPACE_MODEL_TIMEOUT_SECONDS`：模型调用超时时间，默认 `60`。
- `WORKSPACE_ENABLE_AUDIT_EVENTS`：是否开放审计事件接口，默认 `true`，生产可设为 `false`。
- `WORKSPACE_CORS_ORIGINS`：允许访问后端的前端地址，多个地址用英文逗号分隔。

## 启动方式

推荐从项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\start-workspace.ps1
```

启动脚本会自动读取根目录 `.env`。本地首次配置可以复制 `.env.example` 为 `.env`，再填写模型密钥和数据库连接。

默认地址：

- 前端：`http://127.0.0.1:5174/workspace`
- 后端：`http://127.0.0.1:8787/api/health`

## Docker Compose 启动

项目根目录已提供 `docker-compose.yml`，包含 PostgreSQL、Python 后端和前端静态服务。

```powershell
Copy-Item .env.example .env
docker compose up --build
```

启动前需要把 `.env` 里的 `AGNES_API_KEY` 改成真实模型密钥。

## 验证方式
